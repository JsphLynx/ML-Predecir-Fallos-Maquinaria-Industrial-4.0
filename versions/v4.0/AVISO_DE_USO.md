# Alcance de uso

Dataset y generador didácticos, 100 % sintéticos. No son datos operativos, inventario, ficha OEM ni gemelo digital validado de ArcelorMittal Sestao. No hay colaboración, aprobación ni certificación de ArcelorMittal o SMS group implícita. Los nombres industriales sirven de contexto documental.

No utilizar las consignas, umbrales o relaciones simplificadas para controlar equipos, ajustar protecciones o decidir intervenciones reales. La distribución de fuentes externas conserva sus derechos; el informe contiene enlaces y síntesis, no redistribuye datasets de terceros. El proyecto no acredita rendimiento predictivo ni ahorro.
